# CHIFFONTE ECサイト

## プロジェクトの概要

無添加シフォンケーキ「CHIFFONTE」のECサイトです。

同時制作したブランディングサイトと世界観を統一しながら、商品情報・キャンペーン・購入ガイドを整理し、ユーザーが商品購入まで進みやすい構成を意識して制作しました。

季節限定商品や商品一覧を掲載し、各商品からBASEの購入ページへ遷移できる導線を設けています。
